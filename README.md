# THE STOCK ROOM — A-to-Z 3D + LIVE DEMO

Premium black/gold educational website with separate pages, 3D scenes, course content, login/signup UI, demo dashboard, leaderboard, certificate, support AI UI, legal pages, and responsive layouts.

## Live market feed
- BTC/USDT uses a public Binance WebSocket for the live price display.
- The Trading Terminal embeds TradingView charting for BTC/USDT, Gold/XAUUSD and Silver/XAGUSD.
- The chart is for market observation/education. Data availability and any exchange-specific delays depend on the provider.
- No API secret is stored in the frontend.

## Demo-only safety
- Initial virtual balance: $5,000.
- Profit target: $400.
- Required trading days: 7.
- Leaderboard milestone: 1,000 points.
- Maximum demo lot size: 0.20.
- Virtual Buy/Sell buttons never connect to a broker or exchange and never move real money.

## Important
This is a front-end educational/demo prototype. Persistent authentication, server-side user accounts, private AI support, secure backend order simulation, and production analytics require a backend. Do not put private API keys in GitHub Pages frontend files.
